# About Me:
I design and ship backend systems end to end: APIs, event-driven microservices, and the data layer underneath them. Backend is where I go deep, but I work full-stack when the product needs it, and I like owning things all the way into production.
 
Most of my work lives in private repos, so this profile is a sample rather than the whole picture. Projects live on my [portfolio](https://portafoliotetsu.web.app/).

## Focus
- Backend architecture: microservices, REST APIs, event-driven systems
- Data: relational modelling, query performance, multi-tenancy
- Cloud and infrastructure: containers, CI/CD, keeping services healthy in production
- Industrial IoT: connecting physical equipment to the cloud
- AI integration: building LLM capabilities into real products
